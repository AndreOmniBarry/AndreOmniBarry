### About

I design, build and ship complete products end to end — web, mobile and AI — for churches, communities and businesses.

- **AI in real products** — Claude and Groq models, retrieval and multi-agent assistants, with tenant isolation enforced in the database
- **Full stack in TypeScript and Python** — Next.js and React front ends, Node.js and FastAPI back ends, PostgreSQL on Supabase
- **Web to mobile** — native Android (Java) and Capacitor apps, signed and released from CI
- **Security by default** — HMAC-signed integrations, row-level security, encrypted queues and audit trails
